# home-manager

Personal Flutter Web app for home management: utilities (electricity/water), expenses, shopping lists, and bill photos.

## Requirements

- Flutter **3.29.2** (Dart 3.7.2)
- Web only — no App Store, no Developer Mode

## Run locally

```bash
flutter --version   # expect 3.29.2
flutter pub get
flutter run -d chrome
```

## iPhone (PWA)

After deploy, open the URL in Safari → **Share** → **Add to Home Screen**.
